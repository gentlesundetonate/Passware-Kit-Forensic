# Features

- The software supports dictionary and mask attacks to recover various types of passwords efficiently.
- It allows remote agents to recover passwords from multiple machines simultaneously for effective forensic analysis.
- Detailed reports are generated post-recovery, providing insights into the process and results obtained.
- The Forensic edition is specifically designed for laboratory use, catering to complex and high-stakes recovery scenarios.
